# 🚀 Introdução ao CRUD com PHP e MySQL

Repositório didático destinado ao estudo das operações fundamentais de manipulação de dados (**CRUD**) utilizando **PHP (PDO)** e **MySQL (XAMPP)**.

---

## 📌 O que é CRUD?

**CRUD** é um acrônimo para as quatro operações básicas realizadas em sistemas de armazenamento de dados:

* **C - Create** *(Criar/Inserir)*: Adiciona novos registros ao banco de dados.
  * **SQL:** `INSERT INTO` | **HTTP:** `POST`
* **R - Read** *(Ler/Consultar)*: Recupera e exibe dados existentes.
  * **SQL:** `SELECT` | **HTTP:** `GET`
* **U - Update** *(Atualizar/Alterar)*: Modifica informações já cadastradas.
  * **SQL:** `UPDATE` | **HTTP:** `PUT` ou `PATCH`
* **D - Delete** *(Deletar/Remover)*: Remove registros do banco de dados.
  * **SQL:** `DELETE` | **HTTP:** `DELETE`

---

## 🛠️ Tecnologias e Ferramentas

* **PHP 8.x** (Lógica de backend)
* **MySQL / MariaDB** (Banco de dados relacional)
* **PDO (PHP Data Objects)** (Abstração e acesso seguro ao banco)
* **XAMPP** (Servidor Web Apache + MySQL)
